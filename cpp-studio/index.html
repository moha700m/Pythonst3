02 / حالة البناء

1
إرسال آمنيُرسل المصدر إلى وسيط Cloudflare، ولا يظهر مفتاح GitHub في المتصفح.
2
بناء حقيقي على WindowsGitHub Actions + MSVC x64، مع اختيار Console أو Windows GUI.
3
متابعة مباشرةالصفحة تتابع حالة الـ workflow تلقائياً حتى اكتمال البناء.
4
تشغيل والتقاط صورةيحاول Windows تشغيل البرنامج والتقاط صورة لنافذته، أو يعرض مخرجات Console الفعلية.
5
حفظ المعاينة وEXEتظهر الصورة داخل الصفحة وتقدر تحفظها من الجوال، مع تنزيل ملف EXE.
حالة البناء ونتيجة المعاينة تظهر هنا في نفس الصفحة.
المعاينة تُلتقط بعد تشغيل البرنامج على Windows Runner. بعض البرامج التي تتطلب صلاحيات أو ملفات خارجية أو تفاعلًا خاصًا قد لا تظهر صورتها. تشغيل البرنامج داخل المتصفح غير مدعوم.

لا تضع كلمات مرور أو مفاتيح API أو بيانات خاصة داخل كود الاختبار.
