# PYTHONST3

**CODE BEYOND LIMITS.**  
بيئة تطوير Python عربية بواجهة Cyberpunk، تجمع بين تطبيق iOS أصلي وموقع ويب متكامل.

> **المعمارية المعتمدة:** Native iOS IPA + Web Companion، تشغيل محلي أولاً، وتشغيل Linux سحابي اختياري عند الحاجة وبعد موافقة صريحة على أي تكلفة.

## الرؤية

Pythonst3 ليس مجرد محرر داخل المتصفح. المنتج يتكون من تطبيق iOS أصلي يضم CPython مدمجاً، وموقع ويب يشغل Python المتوافق عبر Pyodide، مع تجربة مشاريع متقاربة ومزامنة اختيارية. المشاريع التي تتطلب نظام Linux أو subprocess أو مكتبات غير قابلة للبناء على iOS يمكن توجيهها لاحقاً إلى Cloud Runtime معزول.

## المنصات

| المنصة | التنفيذ | التشغيل |
|---|---|---|
| iPhone / iPad | SwiftUI + CPython Embedded | محلي على الجهاز |
| Web / PWA | React + TypeScript + CodeMirror + Pyodide | داخل المتصفح |
| Cloud Runtime | خدمة حاويات معزولة، اختيارية | Linux عند الطلب وبعد الموافقة |

## مبادئ غير قابلة للتفاوض

1. لا توجد موارد سحابية مدفوعة أو اشتراكات أو خدمات خارجية مدفوعة دون موافقة المستخدم.
2. لا توضع مفاتيح API أو شهادات توقيع أو أسرار في المستودع.
3. لا ندّعي أن iOS أو Pyodide يشغّلان كل مكتبات Python بلا قيود.
4. نتحقق من التوافق والتراخيص قبل إدخال أي مشروع أو مكتبة خارجية.
5. نحافظ على الملفات محلياً افتراضياً، والمزامنة اختيارية وبموافقة المستخدم.
6. لا نعلن عن IPA قابل للتثبيت قبل نجاح البناء والتوقيع والتحقق.
